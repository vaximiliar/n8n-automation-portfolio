# Lead Qualification

## Overview

This workflow automatically analyzes incoming leads and classifies them as Hot, Warm, or Cold based on the content of the customer message.

## Features

- Analyze incoming lead messages
- Assign lead priority automatically
- Add a qualification reason
- Update Google Sheets

## Tech Stack

- n8n
- JavaScript
- Google Forms
- Google Sheets

## Workflow

Google Form → Google Sheets → JavaScript Qualification → Google Sheets
