# Appointment Booking Automation

## Overview

This workflow automatically creates a meeting in Google Calendar, sends a confirmation email to the customer, and updates the booking status in Google Sheets.

## Features

- Capture preferred meeting date and time
- Create Google Calendar event
- Send booking confirmation email
- Update booking status automatically

## Tech Stack

- n8n
- Google Forms
- Google Sheets
- Google Calendar
- Gmail

## Workflow

Google Form → Google Sheets → Google Calendar → Gmail → Google Sheets
